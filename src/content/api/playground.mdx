# Decode Playground

The [Decode Playground](/playground) runs Atlas decoding in your browser. No API key and no sign-in.

## What it is for

- **Developers** validating RPC event JSON or XDR before wiring production code
- **Explorer users** checking why an event is **decoded** or **raw**

## What it is not

- Deploying or invoking Soroban contracts (use Stellar Lab or your CLI)
- Uploading WASM or publishing schemas (use the [Schema Registry](/schemas) and CLI)

## How to use

1. Open [/playground](/playground) (full-screen editor, **testnet** only for now).
2. Select the emitting **contract ID** from the registry list.
3. Paste payload as **JSON** (`topicsJson` / `valueJson`) or **XDR** (`topics_xdr` / `value_xdr`).
4. Click **Decode** (or ⌘/Ctrl+Enter).

The Naralabs web app calls Atlas on your behalf; you never paste an `nl_api_` key into the playground.

## From the explorer

On an event detail page, use **Try in Playground** to prefill contract ID and payload (XDR when available).
