# Atlas API Overview

Atlas exposes REST APIs for explorer reads, on-demand event decoding, and SEP-0048 schema registry operations. Most endpoints live under `/v1`.

## Base URL

| Environment | URL |
| --- | --- |
| Local | `http://localhost:8080` |
| Production | Configure via `ATLAS_API_URL` |

The Naralabs website proxies browser reads through `/api/atlas/*` (BFF). Integrations should call Atlas directly with an [API key](/docs/api/api-credentials).

## Credentials summary

| Credential | Prefix | Use case |
| --- | --- | --- |
| API key | `nl_api_` | Decode API + programmatic explore reads |
| Publish token | `nl_live_` | Schema publishing (`POST /v1/schemas`) |

See [API Credentials](/docs/api/api-credentials) and [Quickstart](/docs/api/quickstart).

## Common parameters

| Parameter | Description |
| --- | --- |
| `network` | Stellar network (`testnet`, `mainnet`, `futurenet`) |
| `page` | Page number (1-based, default `1`) |
| `page_size` | Items per page (default `20`, max `100`) |

## Paginated response

List endpoints return:

```json
{
  "items": [],
  "total": 0,
  "page": 1,
  "page_size": 20
}
```

## Endpoints

### Decoder

| Method | Path | Auth | Description |
| --- | --- | --- | --- |
| POST | `/v1/decode` | API key | Decode one raw Soroban event |
| POST | `/v1/decode/batch` | API key | Batch decode (max 50) |

See [Decode API](/docs/api/decode-api).

### Explore (read)

| Method | Path | Auth | Description |
| --- | --- | --- | --- |
| GET | `/health` | None | Service health |
| GET | `/v1/stats` | API key recommended | Network statistics |
| GET | `/v1/home` | API key recommended | Homepage aggregate payload |
| GET | `/v1/events` | API key recommended | Paginated events list |
| GET | `/v1/events/{id}` | API key recommended | Event detail |
| GET | `/v1/contracts` | API key recommended | Paginated contracts list |
| GET | `/v1/contracts/{id}` | API key recommended | Contract detail |
| GET | `/v1/contracts/{id}/events` | API key recommended | Contract events (paginated) |

### Schema registry (SEP-0048)

| Method | Path | Auth | Description |
| --- | --- | --- | --- |
| POST | `/v1/schemas` | Publish token | Publish new schema version |
| GET | `/v1/schemas` | None | List schemas (`limit`, `offset`, `search`) |
| GET | `/v1/schemas/{contract_id}` | None | Latest schema per event on a contract |
| GET | `/v1/schemas/{contract_id}/{event_name}` | None | Get schema (`?version=` optional) |
| GET | `/v1/schemas/contracts` | None | Contract-level schema bundles |
| GET | `/v1/schemas/summary` | None | Registry aggregate stats |

Registry list pagination uses `limit` / `offset`, not `page` / `page_size`.

### Events (`GET /v1/events`)

| Parameter | Description |
| --- | --- |
| `network` | **Required**. `testnet`, `mainnet`, … |
| `page`, `page_size` | Pagination (max `page_size` 100) |
| `search` | Event ID, contract ID, txn hash, payload |
| `event_type` | Filter by type symbol |
| `decode_status` | `decoded` or `raw` |

`GET /v1/events/{id}?network=` returns full topics, value JSON, XDR, and decode metadata.

### Contracts (`GET /v1/contracts`)

| Parameter | Description |
| --- | --- |
| `network` | **Required** |
| `page`, `page_size` | Pagination |
| `search` | Contract ID |
| `schema_status` | `decoded` or `raw_only` |

`GET /v1/contracts/{id}`: summary and schema info.  
`GET /v1/contracts/{id}/events`: paginated events for one contract (same filters as `/v1/events`).

## OpenAPI / Scalar

Atlas serves interactive API docs at `/docs` on the Atlas server (Scalar UI).
