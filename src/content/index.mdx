# NaraLabs Documentation

**NaraLabs** is semantic infrastructure for Soroban: indexed events, SEP-0048 schema registry, and the Atlas decode API.

## What you can do

- Browse **recent Soroban events** and decode status in the [explorer](/docs/explorer/overview)
- Explore **contracts** and **published schemas**
- Call the **Atlas API** to decode raw events or query indexed activity

## Local development

1. **Start Atlas** (API + indexer):

```bash
cd naralabs-atlas
docker compose up -d
```

2. **Start the web app**:

```bash
cd naralabs-frontend
cp .env.example .env
npm install
npm run dev
```

3. Open [http://localhost:3000](http://localhost:3000) (explorer) and [http://localhost:3000/docs](http://localhost:3000/docs) (this site).

Key env vars: `ATLAS_API_URL`, `NEXT_PUBLIC_STELLAR_NETWORK`. See `.env.example`.
